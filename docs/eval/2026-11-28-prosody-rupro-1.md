## 4. Что значит вердикт

- **Что проверено.** Индекс `PROSODY-RULE v1` отделяет слова с pitch accent по разметке
  `word_pa` RuPro от слов без акцента в той же IP. Это верно на монолингвальной части RUEG 1.0
  после исключений правила.
- **Что не проверено.** PASS не говорит о воспринимаемой выделенности вообще, о смысловом
  акценте (фокусе), о дикции и о просодии целиком. Об аудиомоделях и их слухе прогон ничего не
  говорит. PASS не даёт READY audio backend: `backend = "none"`, Gate 0 и #90 не меняются.
- **Времена слов.** Внутри расчёта времена слов дают только ASR. Интервалы EXB и слов RuPro
  задают только срез IP.
- **Метки.** `word_pa` — экспертная разметка RuPro. Таблица OSF `ip_pos.csv` явной лицензии не
  имеет: у проекта OSF поле лицензии пустое. Поэтому таблица и метки по словам не публикуются и в
  git не попадают. CC0 RUEG 1.0 покрывает граф RuPro внутри архива RUEG, но не таблицу OSF. Код
  сверил с графом метки 6 380 слов IP из записей, где число токенов графа равно числу событий
  EXB: 6 371 совпали, 8 IP с расхождением исключены.

## 5. Ограничения

- Один корпус: монолингвальная часть RUEG, 37 говорящих, подростки и взрослые.
- Речь — пересказ в формальной и неформальной ситуации, запись со смартфона. IP короткие:
  медиана — 2 слова.
- Ошибки ASR и выравнивания слов ASR со словами IP. Из размеченных слов с акцентом 568 не
  получили слова ASR.
- Цифры согласия разметчиков RuPro для наличия акцента нет (`0037` § 6). `word_pa` — проекция
  слоговой пометы на слово при сборке корпуса.
- Пары одного говорящего зависимы. Кластерный CI по говорящим учитывает эту зависимость. CI по
  записям дан для сравнения.
- 632 IP из 2 757 исключены до ASR, в основном из-за записей без времён RuPro. Вывод относится
  к оставленной части.
