## 3. Контроли

Расшифровка контроля — «сегодня вечером». Порядок MU: 1 = «сегодня», 2 = «вечером». Порядок UM —
наоборот. Верный ответ — `0`.

| контроль | MU | UM | исход |
|---|---|---|---|
| `S0` (тишина) | `1` | `1` | не пройден: два `wrong` |
| `N1` (розовый шум) | `1` | `1` | не пройден: два `wrong` |
| `T1` (тон 440 Гц) | `1` | `1` | не пройден: два `wrong` |

Контроли пройдены, если все 6 ответов — `0`. Пройдено 0 из 6.

Что значит исход каждого контроля:

- **`S0`.** На записи нет звука. Модель выбрала слово, а не `0`. По 0036 § 4 ответ `1` или `2` на
  контроле показывает, что модель берёт ответ из текста, а не из звука.
- **`N1`.** Шум без речи. Исход тот же, вывод тот же.
- **`T1`.** Тон без речи. Исход тот же, вывод тот же.
- **Позиция, а не слово (описательно).** У каждого контроля оба порядка дали `1`. В MU это
  «сегодня», в UM — «вечером». Ответ следует номеру варианта, а не слову.

## 4. Вывод и его смысл

Правило 0036 § 3 даёт вывод `audio advantage shown`, когда прогон полный, нижняя граница CI `G`
больше 0 и нижняя граница CI точности audio больше 0,5. Здесь прогон полный, нижняя граница `G`
0,025 > 0, нижняя граница точности audio 0,55 > 0,5. Код записал `audio advantage shown`.

Правило печатает исход контролей рядом с выводом. Если хотя бы один ответ контроля не `0`, правило
добавляет к выводу текст «контроли не пройдены: ответ из текста вместо звука не исключён». Здесь
все шесть ответов — `1`. Код добавил этот текст. Вывод кода и текст правила совпадают.

Итог по правилу: **`audio advantage shown`; контроли не пройдены: ответ из текста вместо звука не
исключён.** Границы вывода — из правила:

- опыт диагностический, это не Gate 0 и не Gate 1;
- вывод не даёт READY, не закрывает #90 и не меняет `backend = none`;
- выборка — уже использованный dev-материал E-R `gpu-ext-149`, не независимая квалификация;
- новая попытка — только по решению владельца; правило после просмотра ответов не меняется.

## 6. Чего опыт не устанавливает

- Слышит ли модель ударение. Выигрыш audio есть, но на неречевом звуке модель выбирает первый
  вариант. Источник выигрыша в звуке этот опыт не разделяет.
- Перенос на другой материал. 20 реплик — один набор dev-клипов. CI `G` широкий: 0,025–0,30.
- Слух модели на других задачах: Q-S, другие модели, runtime и облачный контроль.
