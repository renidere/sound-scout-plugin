# Приёмка T07 и T08: отрицательные проверки

Критерии T07 и T08 из `docs/spec/REQUIREMENTS.md` (раздел 10) с опорой на R09, R10, R11, и тесты,
которые их проверяют. Сквозные проверки собраны в `tests/test_negative_t07_t08.py`, частные — в
модульных тестах. Запуск: `uv run pytest tests/test_negative_t07_t08.py`.

Backend во всех тестах — двойник `FakeBackend` и его варианты (медленный, считающий вызовы,
выходящий в сеть). Такие тесты проверяют контракт и обработку отказов, а не способность слышать
(T03). До `speech_analyze` двойник доходит через обёртку над `app.analyze`, а это одна функция для
CLI и MCP.

Конфигурация — только local-only: `config.KNOWN_BACKENDS = ("none",)`, внешнего backend нет. Поэтому
пункты, которые R09 и T08 относят к выбранному внешнему backend (outcome unknown без
автоматического повторного платного вызова, provider request ID, облачная стоимость), имеют статус
`not_applicable`. Их проверяют, когда внешний backend выбран и разрешён владельцем.
