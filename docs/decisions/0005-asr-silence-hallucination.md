# 0005 — Галлюцинации ASR на тишине: доверие к тексту по `suspect_hallucination`, не по вероятностям

- **Статус:** принято.
- **Дата:** 2026-11-18.
- **Задача:** [#53](https://github.com/renidere/sound-scout-plugin/issues/53); найдено при работе над
  [#19](https://github.com/renidere/sound-scout-plugin/issues/19).
- **Основание:** `docs/spec/REQUIREMENTS.md` R03, R05 (сомнительное слово — `uncertain`, не
  реплика пользователя), T05 (ноль уверенных выдуманных реплик на отрицательных контролях),
  раздел 4 (контракт результата), раздел 6 (ASR-процедура).
- **Дополнено:** `0021-asr-vad-hallucination.md` (#135) — сигнал `no_vad_speech` для текста
  на шуме и тоне, где речи по VAD нет.
- **Код:** `src/sound_scout/asr.py` (`hallucination_signals`, `trusted_segments`,
  `suspect_segments`, `HALLUCINATION_SIGNALS`), `schema/result.v1.schema.json`
  (`transcript.suspect_segments`, контракт `1.2`).

## Наблюдение

Установленная модель (faster-whisper, CPU/int8, параметры `asr.INFERENCE_PARAMETERS`) на 5 с
цифровой тишины отвечает не пустым транскриптом, а уверенной короткой фразой: вероятности слов
около 0.9, собственные сигналы Whisper (`no_speech_prob`, `avg_logprob`, `compression_ratio`) в
норме. Текст фразы здесь намеренно не приводится. Это проверяет slow-тест
`test_real_model_on_five_seconds_of_silence_is_empty_or_flagged` на реальной модели из локального
кэша.

Поэтому порог по вероятностям слов выдумку не отличает: уверенная выдумка над тишиной проходит
любой разумный порог, а настоящая тихая или неразборчивая речь может его не пройти. Выдумку ловит
правило по сигналу: сегмент с текстом над цифровой тишиной (RMS ниже `SILENT_SPAN_RMS_DBFS`,
сигнал `silent_span`) или с собственными сигналами Whisper за их порогами получает
`segments[].suspect_hallucination: true` и список `hallucination_signals`; `flags` транскрипта
содержит `suspect_hallucination`.

## Решение

1. **Одно правило доверия.** Потребители транскрипта опираются на
   `segments[].suspect_hallucination` / `flags`, а не на вероятности слов. Единственная функция
   выбора доверенного текста — `asr.trusted_segments(raw) -> (trusted, flagged)`: сегменты с
   текстом, разделённые только по флагу; сегмент без текста не попадает ни в один список.
   Отсутствующий или не-`bool` флаг — `ValueError`: доверие по умолчанию не выдаётся.
2. **Сырой транскрипт не меняется** (R05). Функция возвращает те же объекты сегментов и ничего не
   переписывает; текст помеченного сегмента остаётся для аудита только в `asr/raw.json`.
3. **Контракт результата `1.2`.** Обязательное поле `transcript.suspect_segments`: элементы
   `{start, end, signals, certainty: "uncertain"}` **без текста**, их строит
   `asr.suspect_segments(raw, duration_s)` (интервал обрезается по длительности источника).
   Схема проверяет форму элемента и словарь сигналов; `schema.validation_errors` — что
   `start <= end <= source.duration_s` (нулевая длина допустима: такие сегменты Whisper тоже
   выдаёт, скрывать их нельзя) и что без `transcript.raw` поле пустое;
   `findings.validate(..., run=run)` сверяет поле с `asr/raw.json` этого run.
4. **Потребители.**
   - Pipeline (`app._asr_stage`) заполняет поле; без выполненного ASR оно `[]`. Строка
     ограничения `ASR: есть сегменты suspect_hallucination` остаётся.
   - `findings.build` сопоставляет findings только со словами доверенных сегментов: исправление
     никогда не цитирует выдуманную фразу в `original`. Сам finding аудиомодели остаётся.
   - `report.render` выводит интервалы с признаками под пометкой «текст не считается
     произнесённым»; текст в `report.md` и краткий ответ не попадает.
   - Eval runner (`eval/runner._confident_raw_segments`) считает уверенные выдумки на контролях
     через ту же функцию; неверная форма raw — причина «§ 9 не подтверждён».

## Рассмотренные варианты

- **Порог по вероятностям слов** — отклонено: см. наблюдение, выдумка уверенная.
- **Помеченный сегмент в `transcript.corrections` с `certainty: "uncertain"`** — отклонено: у
  исправления обязательны `original`/`corrected`, выдуманный текст пришлось бы показать в отчёте,
  а слой исправлений смешался бы с фильтром.
- **Только общая строка в `limitations`** — отклонено: по ней не видно, какой интервал
  недоверенный, и валидатор не может её проверить.

## Границы

Пороги правила (`HALLUCINATION_RULE`) и ТЗ не меняются. Правило не доказывает, что непомеченный
текст произнесён: это ограничение ASR в целом, его проверяют отрицательные контроли T05.
