## 8. Сторож

Стек #147 (`vast.arm`, `vast.watch_tick`) взводит два таймера `systemd-run --user` до create:

- `sound-scout-gpu-<attempt>-watch` — тик раз в 60 с. Destroy всех инстансов попытки: дедлайн;
  исход create неизвестен; больше одного инстанса с меткой; пульс агента старше 300 с; запрошен
  destroy; наблюдаемый расход ≥ 0,65 USD.
- `sound-scout-gpu-<attempt>-cutoff` — на дедлайн и на дедлайн + 15 мин: безусловный destroy, затем
  поиск потерянного create по метке.
- На хосте: `onstart` завершает PID 1 через дедлайн + 300 с; `hostrun.py serve` останавливает vLLM
  на дедлайне. Это останавливает GPU, но не storage.

## 9. Удаление и проверка

1. `download`: архив с хоста, SHA-256 архива и каждого файла по `SHA256SUMS`. Destroy идёт и при
   отказе сверки.
2. `DELETE /api/v0/instances/<id>/` для каждого id попытки. Stop не используется: storage
   тарифицируется.
3. Отсутствие: в `GET /api/v1/instances/` с фильтром по метке нет id, и `GET /api/v0/instances/<id>/`
   не отдаёт инстанс. Затем `absence_verified`, `closed`, таймеры остановлены.
4. Полный список инстансов аккаунта пуст.
5. Кредит: сразу после `closed` и через 24 ч. Дельта ≤ 1,00 USD.
6. Диск хоста проверить нельзя. Там только синтетика и открытые веса.
