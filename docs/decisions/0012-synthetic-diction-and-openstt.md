## Вопрос

Ни в одном открытом наборе нет человеческой разметки ошибок дикции, а в held-out `pilot-1` после
#78 нет ни одного клипа `pronunciation`. Контроль «речь с ошибками ASR» в #78/#84 — только две
смеси RINCO с шумом. Как пополнить черновик синтетикой с известным дефектом и реальной речью, на
которой локальный ASR ошибается, не выдав автоматику за разметку?

## Правила

1. **TTS — Piper 1.8.0, голос `ru_RU-denis-medium`** на закреплённой ревизии HF, только CPU.
   Silero `v5_cis_base` не берём: его русские голоса — дикторы из стран СНГ, акцент смешался бы с
   дефектом (R04); модель исполняет код из файла, URL без ревизии, выравнивания нет.
2. **Дефект вносится на уровне фонем espeak-ng.** Ошибка ударения — перенос `ˈ` и смена качества
   гласных (ударная — полная, бывшая ударная — редуцированная); искажение слова — заменённая
   последовательность фонем. Один дефект на клип.
3. **Интервал — только из выравнивания Piper** (отсчёты на id фонемы, модель патчится в памяти
   пакетом `onnx`). Отсчёты раскладываются по фонемам правилом `PiperVoice.synthesize` 1.8.0: BOS,
   каждая фонема со своими id и PAD, EOS; сумма обязана равняться длине аудио. Без выравнивания,
   при несовпадении фонем целевого слова с таблицей, при слиянии слов espeak и при символе вне
   карты фонем синтез отказывается работать: оценённых интервалов нет. Ресемплинг 22 050 → 16 000
   Гц через ffmpeg сохраняет шкалу (тест: ±10 мс).
4. **Запись в манифест:** `synthetic: true`, `categories: ["pronunciation"]`, не контроль;
   `synthetic` у контроля — ошибка валидатора. Разбиение по хэшу группы: 10 held-out, 6 dev
   (`SYNTHETIC_HELDOUT_GROUPS`; запас на отсев на слух при минимуме 5 событий дикции в held-out).
   В PROTOCOL § 2 неверное лексическое ударение в конкретном слове — событие `pronunciation`.
5. **Файл дефекта — `synthetic/<id>.json`, не разметка** (`not_a_human_label: true`, схема
   разметки его не принимает). `labels/<id>.json` — пустой шаблон. Разметчик слушает клип вслепую
   и сверяется с файлом дефекта только после разметки (LABELING.md); клип, где дефект не слышен,
   исключается из held-out до фиксации.
6. **На синтетике не запускается ни ASR, ни другая модель** — ни на dev, ни на held-out. Единственная
   модель — TTS, которая создаёт клип.
7. **Open STT `asr_calls_2_val` — только dev.** Архив читается потоком, без распаковки по его
   путям; берутся только обычные файлы с именем `asr_calls_2_val/<hex>/<hex>/<12 hex>.(wav|txt)`,
   WAV ≤ 4 MiB, TXT ≤ 4 KiB. Пул — пары 2,5–15 с, ≥ 4 слов, только кириллица, порядок
   `sha256(stem)`, первые 120. Held-out-записи манифеста команда не читает.
8. **Отбор, а не подтверждение.** Локальный ASR (путь `analyze`, `asr_review.transcribe_file`)
   идёт по пулу до 5 кандидатов. Кандидат — WER ≥ 0,25 после нормализации (нижний регистр,
   `ё → е`, только буквы). Меньше 3 — выход 1, манифест не меняется. Кандидат входит в манифест как
   `corrupted_asr` с `asr_error_status: candidate`; `confirmed` ставит только человек по листу
   `asr-review/<id>.json` (правило 12 решения 0009). В stdout — только id, WER и статус: это записи
   реальных звонков.

## Таблица слов

Предложения нейтральные, 9–11 слов, целевое слово отделено от краёв минимум двумя словами.
`correct_ipa` сверяется с espeak-ng, встроенным в piper-tts 1.8.0.

| id | Дефект | Слово | Как надо → как сказано |
|---|---|---|---|
| `stress-zamok` | ударение, омограф | замок | замОк → зАмок |
| `stress-muka` | ударение, омограф | мука | мУка → мукА |
| `stress-atlas` | ударение, омограф | атлас | Атлас → атлАс |
| `stress-khlopok` | ударение, омограф | хлопок | хлопОк → хлОпок |
| `stress-zvonit` | ударение, орфоэпия | звонит | звонИт → звОнит |
| `stress-torty` | ударение, орфоэпия | торты | тОрты → тортЫ |
| `stress-katalog` | ударение, орфоэпия | каталог | каталОг → катАлог |
| `stress-dokument` | ударение, орфоэпия | документ | докумЕнт → докУмент |
| `drop-biblioteka` | пропуск слога | библиотека | → библитека |
| `drop-soprovozhdenie` | пропуск слога | сопровождение | → сопровожние |
| `drop-velosiped` | пропуск слога | велосипед | → велсипед |
| `slur-interesnogo` | проглоченное окончание | интересного | → интересн |
| `slur-specialistov` | проглоченное окончание | специалистов | → специалис |
| `slur-zamechatelnymi` | проглоченное окончание | замечательными | → замечательн |
| `subst-ryba` | замена согласного | рыба | → лыба (р → л) |
| `subst-shuba` | замена согласного | шуба | → суба (ш → с) |

Отступления от Decision: espeak читает «замок» как замОк и «хлопок» как хлопОк, поэтому
предложения выбраны под это прочтение («висит старый замок» на двери, регион «выращивает
хлопок»), а дефект — обратный перенос ударения. «Замечательными» стоит без следующего слова
«людьми»: espeak вставляет в него служебный символ `"`. Однобуквенные предлоги espeak не сливает
(«в», «с» остаются отдельными фонемными словами). Фонемы искажений записаны вручную, ударение
слова сохранено; только у «сопровожние» взято прочтение espeak (`sʌprʌvˈoʒnʲijɪ`), потому что
выпавший слог был ударным.

## Что найдено в настоящем архиве и итог прогона (2026-11-19)

- Архив `asr_calls_2_val.tar.gz` (805 251 737 Б, SHA-256 закреплён в § 6): 25 900 обычных файлов,
  12 950 пар wav/txt, ни одного каталога, symlink или имени вне шаблона правила 7. Все WAV —
  16 кГц, моно, PCM16; длительность по заголовку 0,32–18,27 с, медиана 1,7 с, в окне 2,5–15 с —
  3 654 клипа до фильтра текста.
- Синтез: 16 клипов, у всех выравнивание покрывает аудио целиком; 10 held-out (6 ошибок ударения,
  4 искажения) и 6 dev. Интервалы целевых слов 0,24–0,64 с.
- Open STT: пул 120, транскрибировано 15 фраз (faster-whisper large-v3-turbo из кэша, offline,
  `cpu_threads` 4), из них 5 с WER ≥ 0,25 (0,26–0,50) — 5 кандидатов `candidate` в dev, листы
  `asr-review/ostt-*.json` написаны с пустыми полями человека.
- Манифест: 40 записей; `check-manifest --draft` — «структура пригодна, корпус не
  квалифицирован»: ждут только `repetition_self_correction` в held-out и пары (записи владельца,
  #29). Ни один кандидат не подтверждён, ни одна разметка не заполнена.

## Ограничения

- Один синтетический голос и в dev, и в held-out: инструмент может научиться голосу, а не дефекту.
- Синтетический дефект — не живая дикция: recall на синтетике не переносится на людей. Runner
  поэтому пишет в отчёт `clips.synthetic` и строку «из них синтетических (TTS)» (R11).
- Слышен ли дефект, решает человек: интервал по построению — гипотеза, пока клип не размечен.
- В модели Piper есть случайный шум ONNX, побитовой повторяемости нет; воспроизводимость состава —
  через SHA-256 клипов в манифесте.
- Open STT: эталон расшифровки сам может ошибаться; расхождение — только отбор кандидата.
